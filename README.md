# Flask REST API

A RESTful User Management API built with Flask, Flask-RESTful, SQLAlchemy, and SQLite.

## Features
- Create User
- Get All Users
- Get User by ID
- Update User
- Delete User

## Technologies
- Python
- Flask
- Flask-RESTful
- SQLAlchemy
- SQLite

## Run Locally

pip install -r requirements.txt

python3 create_db.py

python3 api.py
